# RareBuild

AI destekli ürün stüdyosu. Küçük yapılar, imkânsız yükler.

Bu repo RareBuild sitesinin geliştirme deposudur. İş akışı: görevler Issues'da, geliştirme `staging` branch'ine PR ile, canlıya çıkış `main`'e merge ile.

## Kurulum

Gereksinim: Node 20 veya üstü.

```bash
npm install
npm run dev
```

Geliştirme sunucusu `http://localhost:3000` adresinde açılır.
